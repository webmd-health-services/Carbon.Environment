# System Requirements

* Windows PowerShell 5.1 and .NET 4.6.1+
* PowerShell Core 6+

# Installing

To install globally:

```powershell
Install-Module -Name 'Carbon.Environment'
Import-Module -Name 'Carbon.Environment'
```

To install privately:

```powershell
Save-Module -Name 'Carbon.Environment' -Path '.'
Import-Module -Name '.\Carbon.Environment'
```
